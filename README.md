## Project Overview
A fully responsive, multi-page website designed for a local artisan small business. The platform highlights daily baked goods, brand history, multi-location contact information, and interactive customer enquiry processing.

## Website Goals and Objectives
- Establish an online presence for Artisan Crust Bakery.
- Provide clear information regarding daily product offerings and store locations.
- Streamline custom orders and customer enquiries through an online form.

## Key Features and Functionality
- **Multi-page Architecture:** Includes Home, About Us, Products, Enquiry, and Contact pages.
- **Interactive Forms:** Structured HTML form for product and service requests.
- **Consistent Navigation:** Standardised header links connecting all 5 pages seamlessly.
- **External CSS Styling:** Custom layout rules and responsive styling.
